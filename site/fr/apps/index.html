Applications

Quelques projets que j'ai créés, plusieurs avec une IA m'accompagnant sur une bonne partie du travail.

Exception Rosetta (computerrev)

Application en ligne

Une référence interactive qui met en parallèle la façon dont AArch64, RISC-V, x86 et Cortex-M gèrent les exceptions et les interruptions, pour que changer d'architecture ne signifie pas tout réapprendre depuis le début.

aicli

GitHub

Un proxy pour les CLI de codage IA. Un abonnement Claude Code ou Antigravity couvre bien plus de travail que ce que le même budget achète aux prix de l'API, mais rien ne permettait à mes scripts d'en utiliser plusieurs et de basculer entre elles. C'est ce que fait aicli : les appelants indiquent le type de travail, et aicli choisit la CLI et le modèle à partir d'une table de routage en direct, journalise qui a utilisé quoi, et peut exposer un point de terminaison compatible OpenAI. Il exécute les CLI officielles sous mon propre compte. Claude Code et Antigravity aujourd'hui, d'autres backends prévus.

gdb2dict

Paquet PyPI · GitHub

Un petit utilitaire Python pour GDB qui transforme la sortie de gdb.Value en dictionnaires Python classiques, pour sérialiser directement en JSON des structures C/C++ depuis une session de débogage.

mockerbee

GitHub

Une bibliothèque C++ qui simule des ensembles d'appareils Zigbee ZCL pour tester des passerelles et hubs IoT, avec plusieurs fonctionnalités implémentées par un bot IA autonome via des pull requests.
