Apps

A few things I've built, several of them with an AI pairing most of the way.

Exception Rosetta (computerrev)

Live app

An interactive reference that maps how AArch64, RISC-V, x86 and Cortex-M handle exceptions and interrupts side by side, so switching architectures doesn't mean relearning the vocabulary from scratch.

gdb2dict

PyPI package · GitHub

A small GDB Python helper that turns gdb.Value output into plain Python dictionaries, so C/C++ structures can be serialized to JSON straight from a debug session.

mockerbee

GitHub

A C++ library that mocks pools of Zigbee ZCL devices for testing IoT gateways and hubs, with several of its features implemented by an autonomous AI PR bot.
